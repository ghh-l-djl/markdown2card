# Maintain the browser extension from its built bundle

The browser extension source is unavailable, but Markdown2Card must add a card-image publishing mode while preserving existing behavior. We will maintain a local-only, independently named and versioned unpacked fork by changing its built JavaScript bundle directly, accepting brittle diffs, harder testing, and manual upgrades instead of blocking the integration on unavailable source code. The fork will not be distributed without confirming permission or a project-level license.
